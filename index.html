About
Skagestad Labs started as a small personal project where I could experiment with web development and build useful tools from scratch.

What started with a few simple utilities has gradually grown into a collection of IT tools, calculators and experimental projects.

Most of the tools here are built because I needed them myself, wanted to learn how something worked, or simply thought it would be useful or fun to create.

The project is continuously evolving as I experiment with new ideas, learn new technologies and improve the existing tools.

Everything is built with a focus on being simple, fast and easy to use — without unnecessary complexity.

Built for learning. Built for solving problems. Built for fun.
